## 一些常見問題？
Q : 啊我看你們寫的App有登入功能，是不是一定要登入才能用？
  A : Stargazer 3 大部分功能均可以無需登入，開箱即用的．例如查看自己協助角色，不登入的情況下可以透過查詢UID查看；當然，登入後能夠透過按下首頁頂部的用戶頭像，來看自己擁有的所有角色數據哦~

Q : 要確定誒，你們登入功能居然是在官網填帳密？
  A : 是的，為了降低使用技術門檻，我們特意在App內提供相關功能；在此先聲明一下：我們一如既往，絕不以任何形式截取用戶帳戶、密碼等敏感資料；我們僅會獲取用戶登入官網後的Cookies。當然，您亦可以選擇手動輸入Cookies，Cookies只會在本地存放，不會上載到伺服器；PC版目前僅支援手動輸入，請見諒。

Q : 哈囉，是説第三方平台登入呢？去哪啦？
  A : 由於技術所限，經過我們數次嘗試後仍然沒法成功做到。故目前也無法提供上述方法，實在抱歉

Q : 誒不是，説是重製版，啊結果跟上版根本沒不同，啥意思呀？
  A : 我們優化的重心是在用戶體驗、程序代碼、項目結構優化、維護成本下降等方面。所以，重製過後的介面會和舊版的大致相同。若果您認為介面上有任何可以優化/更正的地方，請別猶如，直接來我們Discord伺服器掛一個issue吧 (拜託不要再放閒聊了）

# Stargazer 3 Closed Beta Recruitment

Hi Trailblazers!

Long time no see (?) I’m Voc, the developer of Stargazer.
Back in early July last year, we started the renewal project for `Stargazer`. However, due to personal reasons (not having enough time to complete it before semester started), we temporarily postponed the discontinuation of Stargazer 2. As Stargazer 2 has become increasingly unstable, we have finally decided to resume the renewal project during the winter break.

Unlike the summer version, this revised version:
    - Introduces support for tablets and large screens
    - Refines UI details
    - Modifies the app update logic
    - Separates all character/relic-related information and images from the main app

After this remake, we will conduct a two-week closed beta for early versions. We invite interested and eligible Trailblazers to apply!

## Frequently Asked Questions

**Q: I see that the app has a login feature. Is logging in mandatory to use the app?**  
**A:** Most functions in Stargazer 3 do not require login and can be used right away. For example, you can check your support characters by searching for a UID without logging in. However, logging in allows you to view all your character data by tapping your avatar on the homepage.

**Q: Just to confirm, does your login function require entering my credentials on the official website?**  
**A:** Yes. To lower the technical barrier, we provide a built-in function in the app. As always, we strictly do not intercept user accounts, passwords, or any sensitive data. We only retrieve the Cookies generated after you log in on the official website. Of course, you can manually enter Cookies instead. These Cookies are only stored locally and are not uploaded to the server. The PC version currently only supports manual input—sorry for the inconvenience.

**Q: Hey, what happened to third-party login options?**  
**A:** Due to technical limitations, we have been unable to implement third-party login despite multiple attempts. We apologize for this inconvenience.

**Q: Wait, isn’t this supposed to be a remake? It looks the same as the previous version. What gives?**  
**A:** Our focus is on user experience, program optimization, project structure refinement, and lowering maintenance costs. As a result, the interface remains largely similar to the previous version. If you have any suggestions for UI improvements, please don’t hesitate to report them in our Discord server (and please avoid posting in general chat!).

**Q: You’ve been working on this for a month, but there are only a few pages?**  
**A:** (Actually, I’m the only one working on this.) While rewriting the app, I aimed for a work-life balance rather than coding non-stop. Sometimes unexpected situations arise that slow down progress. Please understand that one person cannot work at the efficiency of two!
